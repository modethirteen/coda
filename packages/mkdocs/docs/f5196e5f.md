## Why are we migrating?

* Unlock features that can reduce code by 33%.
  * Take a look at this [example on StackBlitz](https://stackblitz.com/edit/vitejs-vite-p8exyj?file=README.md) to see the difference between MobX and React Router. (`main-mobx` and `main-react-router` files)
  * Less code usually correlates to simpler development 😄
* Ease of migration to using the [Remix Framework](https://remix.run/) which in turn will make it easy to get the benefits of the [UFEA architecture](https://coda.io/d/_dYFR3G4AskL/_suuOm)!
  * Take a look at this [Remix blog post](https://remix.run/blog/merging-remix-and-react-router) and how there’s not much of a difference between Remix code and React Router code
  * Further benefits will be seen from the [UFEA architecture value props](https://coda.io/d/_dYFR3G4AskL/_suitU)

## How are we migrating?

Migration will take place in 3 phases.

1. Bumping react-router package from v5 to v6
2. Leverage new react-router features, such as [loaders](https://reactrouter.com/en/main/route/loader) and [actions](https://reactrouter.com/en/main/route/action)
3. Migrate code to [UFEA architecture](https://coda.io/d/_dYFR3G4AskL/_suuOm)

### Phase 1

Phase 1 really is meant to set you up for the future, so this phase focuses on updating react-router from v5 to v6. You’ll want to take advantage of this handy dandy doc: <https://coda.io/d/_dYFR3G4AskL/_suZPO#_lu-sM>. You can add your name to the table in that doc to be the point person that I can contact.

**Timeline**

* Phase 1 will be planned to be 100% done by the end of Q3

**Benefits**

* No benefits besides giving you access to the following phases

### Phase 2

Phase 2 focuses on improving DX by simplifying code, so in this phase you’ll want to start updating your code to use new recommended features and practices, such as:

* [Loaders](https://reactrouter.com/en/main/route/loader) and [actions](https://reactrouter.com/en/main/route/action)
* Follow the [Directory Structure RFC](https://coda.io/d/_dYFR3G4AskL/_suiCx#_lumVl) for structuring your code
* Take the [React-Router class](https://appfolio.slack.com/archives/C04FR4LJM1N/p1715200622506199) that will be released soon™️ by [Luke Herrington](mailto:luke.herrington@appfolio.com)

**Timeline**

* Phase 2 will start in the end of Q2
* It will be done once we have resources for everyone, but improvements are a continuous process that can be addressed in the [#front-end-guild](https://appfolio.slack.com/archives/C04FR4LJM1N)

**Benefits**

* Your code will be reduced by 33% by using react-router 6 new features
  * Take a look at [this StackBlitz](https://stackblitz.com/edit/vitejs-vite-p8exyj?file=README.md) to see a comparison between React-Router and Mobx
* Less code also means simpler to read code!
